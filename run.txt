HOW TO RUN THE PROJECT
======================

1. CREATE AND ACTIVATE A VIRTUAL ENVIRONMENT
   PowerShell:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

   CMD:
   .\.venv\Scripts\activate.bat

2. INSTALL DEPENDENCIES (if not already installed)
   pip install -r requirements.txt

3. TRAIN THE MODEL (first run, or when retraining)
   python brain_tumor_training.py

4. START THE BACKEND
   python backend/app.py

5. OPEN IN BROWSER
   http://localhost:5000

The Flask application will:
- Serve the frontend UI
- Accept MRI image uploads at /api/upload
- Perform tumor classification at /api/analyze
- Generate explainable AI heatmaps
- Use the trained model from backend/models/brain_tumor_cnn.keras

API ENDPOINTS AVAILABLE
- GET /api/health              - Health check
- POST /api/upload             - Upload MRI image
- POST /api/analyze            - Analyze uploaded image
- POST /api/predict/demo       - Demo prediction with sample image
- GET /api/predict/history     - View prediction history
- GET /api/predict/stats       - View prediction statistics
- GET /api/models              - Get available models info
